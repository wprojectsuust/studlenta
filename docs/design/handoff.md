## 4. Поведение

- **Фильтры ленты** пишутся в URL (`?period=week&category=sport&q=…`) — ссылкой можно поделиться.
- **Лайк / избранное** — оптимистично, при ошибке откат и toast. Гость: избранное в
  `localStorage`, после входа — `POST /me/favorites/sync`.
- **Подгрузка** — по `next_cursor` (IntersectionObserver) + кнопка «Показать ещё» для клавиатуры.
- **Форма события**: ошибки после первой отправки, затем на blur; поле — `aria-invalid` +
  `aria-describedby`; сводка `role="alert"`, фокус на первое поле с ошибкой. Ответ 422
  раскладывается по `error.fields`. Черновик сохраняется автоматически (PUT с debounce 2 с);
  кнопки «Сохранить черновик» нет.
- **Модерация**: «Одобрить» без полного чек-листа — сообщение, а не неактивная кнопка;
  возврат и отклонение требуют комментарий; 409 → «Заявку уже обработал другой модератор»,
  перезагрузка очереди.
- **Вход**: 401 → «Неверная почта или пароль», 429 → «Слишком много попыток, подождите минуту».
  Access-токен — в памяти; при 401 на API — один `POST /auth/refresh` (cookie), потом повтор.
- **Анимации** ≤ 200 мс, при `prefers-reduced-motion` — только смена цвета.

## 5. Пограничные случаи

Пустая лента и пустое избранное — `EmptyState` с подсказкой. Заголовок карточки — 2 строки,
описание — 2 (3 на телефоне), место — 1 с многоточием. Нет обложки или битая картинка —
плашка цвета категории (`alt=""`). Загрузка — скелетоны той же геометрии с `aria-busy`.
Ошибка сети — плашка «Повторить», загруженное не исчезает. Снятое событие по прямой ссылке —
«Событие недоступно». «Сегодня» — по `Asia/Yekaterinburg`.

## 6. API

База — `/studlenta/api/v1` (прод) или `/api/v1` (локально). Swagger: `…/api/v1/docs`.
Ошибки: `{"error": {"code", "message", "fields"}}`. Пагинация — `{"items", "next_cursor"}`.
Полный список эндпоинтов с use case'ами — [docs/use-cases.md](../use-cases.md).

## 7. Доступность

Ориентиры: `<aside>` → `<header>` → `<main>`, один `<h1>`. Первый Tab — skip link
«Перейти к ленте». Все действия — нативные `<button>` / `<a>`. Фокус — 3 px кольцо
`--color-focus` (в сайдбаре — `--color-focus-on-dark`). Смена фильтра объявляется через
`aria-live="polite"` («Показано 3 события»). Обложка на странице события — содержательный
`alt`. Масштаб 200 % и ширина 320 px — без горизонтального скролла. В CI фронтенда:
`@axe-core/playwright` на каждом экране и скрипт контраста по токенам всех скинов.
