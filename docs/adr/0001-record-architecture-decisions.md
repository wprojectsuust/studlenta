# ADR-0001: Фиксируем архитектурные решения в ADR

- **Статус:** принято
- **Дата:** 2026-10-23

## Контекст
На хакатоне решения принимаются быстро и в разговоре. Через неделю никто не помнит, почему
нет ORM или комментариев, и обсуждение начинается заново.

## Решение
Каждое значимое решение — короткий файл `docs/adr/NNNN-название.md` по шаблону
`0000-template.md`. Принятые ADR не переписываем: если решение меняется, пишем новый ADR
со ссылкой «заменяет ADR-XXXX».

## Последствия
PR с новой зависимостью или сменой подхода без ADR на ревью не принимается (см. CONTRIBUTING).
