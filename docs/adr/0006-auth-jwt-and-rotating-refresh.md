# ADR-0006: Вход по почте и паролю: короткий JWT + ротируемый refresh в cookie

- **Статус:** принято
- **Дата:** 2026-10-23

## Контекст
Университетский SSO на хакатоне недоступен. Нужны роли (author / moderator / admin) и
безопасная сессия для SPA.

## Решение
- Пароли — argon2id.
- Access — JWT HS256 на 15 минут, фронтенд хранит его в памяти.
- Refresh — случайные 256 бит в cookie `httpOnly; Secure; SameSite=Strict; Path=…/api/v1/auth`,
  в базе только SHA-256. Каждое обновление отзывает старый токен и выдаёт новый (ротация),
  выход отзывает токен.
- Одинаковый ответ на «нет почты» и «неверный пароль»; пароль проверяется даже для
  несуществующей почты, чтобы не выдавать её по времени ответа.
- 10 неудачных входов в минуту на пару IP + почта → 429.

## Последствия
- Лимитер в памяти процесса — верен для одной реплики. При масштабировании — вынести в Redis.
- Роль в JWT действует до 15 минут после смены — для хакатона приемлемо.
