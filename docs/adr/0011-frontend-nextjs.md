# ADR-0011: Фронтенд на Next.js 16 (App Router), standalone-контейнер

- **Статус:** принято
- **Дата:** 2026-10-23

## Контекст
Нужен веб-интерфейс по дизайну с холста (9 экранов, 4 скина, мобильная версия, WCAG 2.1 AA).
Сервис живёт по пути `karrad.tech/studlenta` на VPS с 1 ГБ памяти рядом с другим продом.
Ссылки на события студенты будут пересылать в ВК и Telegram — нужны превью.

## Решение
- **Next.js 16, App Router, `basePath: /studlenta`, `output: standalone`** — отдельный
  контейнер ~60 МБ RAM (лимит 192 МБ).
- **Страница события рендерится на сервере**: данные берутся из API через кешируемую функцию
  (`'use cache'` + `cacheLife('minutes')`), `generateMetadata` отдаёт og:title / og:image.
  Флаги текущего пользователя («лайкнул», «в избранном») догружает клиент.
- **Остальное — клиентские компоненты** с TanStack Query: лента с бесконечной подгрузкой,
  оптимистичные лайки и избранное с откатом при ошибке.
- **Сессия**: access-токен только в памяти, refresh — httpOnly cookie (ADR-0006); один общий
  refresh на пачку параллельных 401.
- **Стили**: CSS-переменные из `docs/design/handoff.md`, скин — `data-skin` на `<html>`, ставится
  инлайн-скриптом до отрисовки (без мигания). Без Tailwind и UI-китов.
- **Без `next/image`**: оптимизатор на сервере с 1 ГБ не нужен, размер обложек ограничивает API.
- **`cacheComponents` включён** — в следующем мажоре Next он станет поведением по умолчанию.
- В разработке и e2e Next проксирует `/api` и `/media` на API (rewrites) — та же топология, что
  у nginx в проде, поэтому cookie и пути одинаковые везде.

## Рассмотренные варианты
- **Vite + React SPA** — проще и легче, но без серверного рендера нет превью в соцсетях.
- **Статический экспорт Next** — без контейнера, но динамические страницы событий не
  отрендерить на сборке.

## Последствия
- Второй образ в GHCR и второй сервис в прод-compose; оба выкатываются одним тегом релиза.
- E2E (Playwright + axe) гоняются на полном стеке: Next → API → PostgreSQL.
- Next 16 отличается от прошлых версий; перед изменениями читаем документацию из
  `frontend/node_modules/next/dist/docs/` (см. `frontend/AGENTS.md`).
