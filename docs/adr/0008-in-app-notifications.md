# ADR-0008: Уведомления только внутри сервиса; комментариев нет

- **Статус:** принято
- **Дата:** 2026-10-23

## Контекст
На дизайне есть колокольчик. Варианты каналов: in-app, e-mail, Telegram-бот. Также решался
вопрос о комментариях к событиям.

## Решение
- Уведомления — таблица `notifications`, показ в колокольчике. Типы: решение модератора
  (одобрено / вернуть / отклонено) и напоминание о событии из избранного за сутки.
- Напоминания рассылает `studlenta-send-reminders`, запуск раз в час по расписанию;
  повтор исключает частичный UNIQUE-индекс.
- Комментариев к событиям в MVP нет — реакции только лайк и избранное.

## Последствия
- Нет внешних зависимостей (SMTP, токен бота) и второй очереди модерации для комментариев.
- Добавить e-mail позже — новый адаптер к порту, сценарии не меняются.
