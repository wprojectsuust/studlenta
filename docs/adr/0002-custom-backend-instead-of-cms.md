# ADR-0002: Свой бэкенд на FastAPI вместо готовой CMS

- **Статус:** принято
- **Дата:** 2026-10-23

## Контекст
Условие задачи разрешает готовую CMS (свободную и с открытым кодом). В первом макете команды
стояли WordPress + MySQL. Ключевое требование — **обязательная предмодерация** с возвратом
на доработку, комментарием модератора и историей решений.

## Решение
Свой API на FastAPI + PostgreSQL. Процесс модерации — явная машина статусов в домене
(`domain/events.py`).

## Рассмотренные варианты
- **WordPress** — есть статусы «черновик / на утверждении», но нет «вернуть с комментарием»,
  истории решений и запрета модерировать своё; всё это — плагины или доработка PHP,
  а лента с фильтрами и скинами всё равно пишется отдельно.
- **Strapi / Directus** — удобная админка, но workflow модерации в бесплатных версиях
  ограничен, а бизнес-правила размазываются по хукам.

## Последствия
- Правила модерации покрыты юнит-тестами и видны в одном файле.
- Админки «из коробки» нет: модераторов назначает CLI `studlenta-create-user`,
  категории — миграцией. Для хакатона достаточно.
- Код открыт (MIT) — условие задачи выполнено.
